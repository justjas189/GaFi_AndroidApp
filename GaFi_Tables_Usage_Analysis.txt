[ LEGACY / UNUSED ]  Safe to leave OUT of the ERD  (7 tables)
================================================================

transactions
    Only referenced in BudgetService.js, which is dead code
    (commented out in config/serviceImports.js and imported nowhere).
    The live app records spending in "expenses" instead.

chatbot_interactions
    Only touched by BudgetDatabaseService_NEW.logInteraction(), which is
    defined but never called anywhere in the app.

chat_sessions
chat_messages
    No supabase.from() reference in app code. Chat persistence is handled
    by ChatContext.js (local/AsyncStorage). These tables appear only in
    old migrations + supabase/cleanup_duplicate_tables.sql.

password_reset_codes
    The custom 6-digit-code system was replaced by Supabase Auth's native
    OTP recovery. AuthContext uses auth.resetPasswordForEmail() +
    verifyOtp(); this table is no longer read or written by the app.

leaderboards
    Superseded by "updated_leaderboard" (+ user_levels for stats).
    Referenced only in old SQL functions, not in app code.

achievement_definitions
    Not queried. Achievement definitions are hardcoded in
    AchievementService.getAchievementDefinitions().
